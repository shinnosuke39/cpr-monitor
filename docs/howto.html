CPR練習モニター 使い方（外科実習Ⅱ 11/18）

https://shinnosuke39.github.io/cpr-monitor/
　部屋の名前は2台とも「cpr1」のまま

① 開く

  1. Mac（プロジェクター）：上のURL →「モニター」→「クリックして開始」（音が出る）。右下の「⛶ 全画面」でSafariの枠が消える
  2. iPad：上のURL →「操作」
  3. iPadの左上が緑で「モニター 1台 つながっています」ならOK
  4. 呼吸を記録する先生のスマホ：上のURL →「呼吸の記録」。iPadの「呼吸数の出し方」を「スマホで記録」に
  5. モニター右上の時計が白＝つながっている（オレンジ＝届いていない）

② 学生がつけたら「つなぐ」

  • 最初は全部「外れ」。波形も数字も出ない
  • 電極をつけた→「心電図」、カプノをつけた→「EtCO₂」を押す（緑＝表示中）
  • SpO₂・血圧は心拍再開（ROSC）のあとでつなぐ
  • 血圧は「血圧を測る」を押すと、数秒の測定のあと表示

③ シナリオの流し方（症例1〜4）

  1. 「シナリオ」で症例を選ぶ →「▶ 時計スタート」（シーン1：倒れた）
  2. 学生が圧迫・換気を始めたら「次へ」（CPR中：心電図は乱れ、心拍数は当てにならない高い数字。ピッは不規則に鳴る）。最初の2分は何もしない
  3. 2:00・4:00・6:00・8:00 の行を押す（または「次へ」）。評価のシーンでは圧迫が自動で止まり、本当の波形が出る。押したシーンは黄色く光る
  4. 学生が圧迫を再開したら、大きな赤いボタン「心臓マッサージ 開始」を押す（右上の圧迫タイマーが2:00でオレンジに光る）
  5. 10:00 ROSC のシーンで洞調律・EtCO₂急上昇。SpO₂・血圧を「つなぐ」→「血圧を測る」

④ EtCO₂（圧迫の質で自動）

ボタン動き（圧迫中だけ）
圧迫 上手（高め）少しずつ 25前後へ。上下に揺れる
ふつう18前後へ
下手（低め）10前後へ
少し上げ気味／少し下げ気味すぐ±3。そのあとも目標が3ずつ上下
自動にしない＋−ボタンの値のまま
圧迫を止めるとゆっくり下がり、再開するとその値からゆっくり上がる。押すとすぐその高さへ寄る。＋−ボタンで直接変えてもよい。

⑤ 次の班の前

  1. 「すべて外す」
  2. 症例を選び直す
  3. シナリオの「0にもどす」（一時停止の後にもう一度押す）

音（モニターのMacから）

心拍の「ピッ」・換気の音・心静止の「ピー」・アラーム。iPadの「音」でそれぞれオン/オフ、音量も変えられる。

⑥ 困ったとき

  • 時計がオレンジ → iPadの操作画面を一度閉じて開き直す
  • ネットが切れた → Macで「操作」を別の窓で開く（Mac 1台で動く）
  • 音が出ない → モニターをクリック／Macとプロジェクターの音量
  • 全画面をやめる → esc キー。もどす → 右下の「⛶ 全画面」（マウスを動かすと出る）か f キー

実習の前に確かめること

  • Macの音量とスピーカー（プロジェクター経由で聞こえるか）。心静止の「ピー」を一度鳴らして確かめる
  • モニターが全画面になっている（「クリックして開始」を押した）
  • Macが途中で暗くならない：システム設定 → ロック画面 →「ディスプレイをオフにする」を「しない」（電源アダプタ接続時）
  • iPadが途中で暗くならない：設定 → 画面表示と明るさ → 自動ロック →「なし」。充電も十分に
  • 2台とも大学のネットにつながっている。iPadの左上が緑
  • 症例1を一度最後まで流してみる（10秒ずつでよい）
